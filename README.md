# JustTranscribe — Claude Code plugin

Transcribe public videos and audio (YouTube, TikTok, Instagram, Facebook,
Pinterest, Google Drive) into timestamped text inside Claude Code, then
summarize, translate or export subtitles.

The plugin connects to the hosted JustTranscribe MCP server
(`https://justtranscribe.ai/api/mcp`). After installing, run `/mcp`, choose
`justtranscribe` and sign in with your JustTranscribe account — no API key to
copy. Docs: https://justtranscribe.ai/mcp
